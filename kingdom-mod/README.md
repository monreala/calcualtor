# Тридесятое королевство — мод для Minecraft 1.7.10

Карточная игра о правлении королевством внутри Minecraft. Требуется Forge 1.7.10 (10.13.4.1614).

## Как играть

- **Клавиша K** открывает игру (меняется в «Настройки → Управление»).
- **Королевский указ** — предмет, который тоже открывает игру по правому клику. Крафт: бумага + золотой слиток (без формы). Есть во вкладке «Разное» в творческом режиме.
- Карту можно перетащить мышью влево или вправо, нажать кнопку сбоку, или нажать ←/→ (A/D).
- **L** или кнопка «Летопись» — свершения, концовки и династия.
- Игра ставит Minecraft на паузу в одиночном режиме. Esc закрывает окно, правление сохраняется.

Прогресс хранится в `.minecraft/kingdom/save.properties`. На сервер ставить мод тоже нужно (из-за предмета), но сама игра у каждого игрока своя.

## Сборка

### Вариант 1. Через GitHub (ничего не нужно ставить)

1. Создайте репозиторий на GitHub и загрузите туда содержимое этой папки.
2. Откройте вкладку **Actions** — сборка запустится сама.
3. Когда она закончится (около 5 минут), откройте запуск и скачайте **kingdom-mod** в разделе Artifacts. Внутри — готовый `.jar`.

### Вариант 2. У себя на компьютере

Нужна Java 17 или 21 (JDK). Java 8 для компиляции Gradle скачает сам.

```
./gradlew build        (Windows: gradlew.bat build)
```

Готовый мод: `build/libs/kingdom-1.7.10-1.0.0.jar`. Его нужно положить в папку `mods` вместе с Forge 1.7.10.

Запустить Minecraft с модом прямо из проекта: `./gradlew runClient`.

Первая сборка долгая: Gradle скачивает Minecraft, Forge и маппинги.

## Устройство кода

```
src/main/java/kingdom/
  KingdomMod.java        главный класс: регистрация предмета и крафта
  ItemDecree.java        предмет «Королевский указ»
  CommonProxy.java       серверная сторона (пустая)
  client/
    ClientProxy.java     клавиша K
    KingdomClient.java   загрузка и хранение партии
    GuiKingdom.java      экран игры: шкалы, карта, кнопки, анимации
    GuiChronicle.java    летопись
  game/                  логика игры, не зависит от Minecraft
    Cards.java           все карты и сюжеты
    Data.java            персонажи, эффекты, прозвища, свершения, концовки
    Game.java            правила, выбор карт, сохранение партии
    Store.java           файл сохранения
    Card.java, Opt.java  устройство карты и варианта ответа
```

### Как добавить карту

В `Cards.java`, внутри блока `static { … }`:

```java
c("treasurer", "Текст карты. {G} заменится на «государь» или «государыня».",
    o("Левый ответ", 0, 5, 0, -5),        // церковь, народ, армия, казна
    o("Правый ответ", 0, -10, 0, 15).msg("Сообщение после выбора"));
```

Нового персонажа добавьте в `Data.java` (`who(...)`): имя, предмет Minecraft для портрета и цвет щита.
